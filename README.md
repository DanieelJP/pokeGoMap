# 🗺️ Poke GO Map

## 📝 Descripción
Poke GO Map es una aplicación web que emula la experiencia de Pokémon GO, permitiendo a los usuarios interactuar con un mapa interactivo que incluye PokéStops, Gimnasios y Pokémon capturables.

## ✨ Características Principales
- 🎮 Emulación de elementos clave de Pokémon GO:
  - 🔵 PokéStops girables
  - 🏋️ Gimnasios para batallar
  - 📍 Pokémon para capturar en el mapa
- 🗺️ Mapa interactivo usando Leaflet
- 🎯 Sistema de captura de Pokémon
- 📱 Diseño responsive y amigable

## 🛠️ Características Técnicas
- Marcadores personalizados para PokéStops y Gimnasios
- Ventanas emergentes con información detallada
- Sistema de filtros para visualizar diferentes tipos de ubicaciones
- Información detallada de Pokémon (tipos, altura, peso)
- Gestión de estados para Pokémon capturados

## 🚀 Tecnologías Utilizadas
- React con TypeScript
- Leaflet para la integración de mapas
- CSS personalizado para estilos y animaciones
- Sistema de componentes modular

## 💻 Instalación y Uso

1. Clona el repositorio:
```bash
git clone https://github.com/DanieelJP/pokeGoMap.git
```

2. Instala las dependencias:
```bash
cd pokeGoMap
npm install
```

3. Inicia el servidor de desarrollo:
```bash
npm start
```

## 🎮 Cómo Jugar
1. Explora el mapa para encontrar PokéStops, Gimnasios y Pokémon
2. Interactúa con los PokéStops haciendo clic y girándolos
3. Visita los Gimnasios para batallar
4. Encuentra y captura Pokémon salvajes
